# SWYNEX Remote IoT Case Study

## 1. Introduction

This project presents a simulated remote IoT monitoring system for collecting, storing, visualizing, and monitoring sensor data.

The project uses simulated sensor readings instead of physical hardware. This allows the complete IoT workflow to be demonstrated safely without performing any unsafe hardware experiments.

## 2. Problem Statement

Remote environments may require continuous monitoring of conditions such as temperature and humidity.

The objective of this case study is to demonstrate how IoT sensor data can be generated, stored, visualized, and monitored using an alert rule.
